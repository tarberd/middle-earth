# Domain Template XML Contract for Onehost Virtual Machine Topology

Onehost consumes pre-rendered libvirt Domain Template XML files generated by external configuration (such as Nix) rather than defining an internal JSON hardware schema. Generating libvirt XML in Rust would require continuously mirroring libvirt's large domain schema and would restrict declarative Nix expressions. Onehost relies on XML role annotations (such as `<disk onehost:role='os-disk'>`) to inject dynamic runtime overlay disks, leaving hardware topology definitions to the template generator.
