# Functional Rust Idioms and Pure Core Architecture

Onehost mandates an expression-oriented, functional programming paradigm in Rust centered on a Pure Core / Imperative Shell architecture. Domain logic, XML transformations, and reconciliation planning are modeled as pure, stateless functions producing immutable data structures (`OnehostPlan`, `DomainXmlElement`), with side effects (libvirt hypervisor interactions, disk image manipulations) strictly relegated behind mockable traits in the lifecycle applier. Production code strictly forbids `unwrap()` and `panic!`, enforcing total error handling via `thiserror` enums, and replaces imperative mutation loops with declarative iterator combinators (`map`, `filter`, `try_fold`) and immutable functional builders.
