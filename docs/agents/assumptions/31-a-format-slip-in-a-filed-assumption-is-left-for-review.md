# A format slip in a filed assumption is left for review

Filed by: orchestrator (shifting-loop-runtime 02)

## Spec says
`docs/agents/issue-tracker.md`: "`Spec says` / "Nothing", or one or two quoted passages, each naming its document." and "**Write once**: an agent never edits or deletes an assumption. An agent that disagrees with one files a new assumption citing the old one by path."

## Assumed
Sometimes a filed assumption breaks the record format without being wrong. For example, it quotes three passages, or it names code where it should describe behaviour. No agent edits such a record, and no new record restates it only to fix the format. The slip waits for the human's review. A new assumption is filed only when an old one's content is wrong, or contradicts another record.
